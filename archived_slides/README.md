# archived_slides/

Retired slide content, kept as a reference for reusable phrasing, diagrams, or
worked examples.

```
archived_slides/
├── en/
└── fr/
```

These files are **not** extracted, not loaded by the deck builder, and not
linked from the docs site. To bring something back into the active curriculum,
copy it into `methodology/<module>.md` (and the FR mirror), then re-extract via
`python3 tools/00_extract_slides.py`.
