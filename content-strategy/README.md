# content-strategy/

Planning and audit documents that shape what gets built — not the curriculum
itself.

```
content-strategy/
└── handout-audit.md     # per-slide audit: which slides should become handouts,
                        # which template to use, and the pointer-slide copy
```

These docs are working notes used while planning content rollouts (e.g. which
slides to convert into handouts, what to retire, where pointer slides go). They
are **not** rendered into slides, handouts, or the docs site.

When a decision in one of these documents lands as actual content, update the
relevant source (`methodology/`, `handouts/`, `templates/`) and either mark the
decision as shipped in the planning doc or remove it.
