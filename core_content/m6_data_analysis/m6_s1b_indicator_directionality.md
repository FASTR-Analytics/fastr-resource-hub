## Indicator directionality

Not every indicator works the same way. Before interpreting a trend, ask: **is an increase good or bad?**

| Going up is good | Going down is good |
|---|---|
| ANC visits | Maternal deaths |
| Facility deliveries | Neonatal complications |
| Immunizations (Penta1, BCG) | Dropout rates |
| OPD visits | Stockout days |
| Coverage % | |

![Indicator directionality](../../resources/diagrams/indicator_directionality.svg)

*Not all increases are good — always ask: does more of this mean better health?*
