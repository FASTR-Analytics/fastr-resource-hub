## Activity: Importing data

**In this hands-on session, we will:**

- Check the instance's stored DHIS2 connection
- Add the indicators we need, from inside FASTR
- Run a DHIS2 import with the four-step wizard
- Read the Ledger and fix what failed

*Participants will import their country's data from DHIS2. Nothing is typed from DHIS2 by hand: the platform fetches it.*
