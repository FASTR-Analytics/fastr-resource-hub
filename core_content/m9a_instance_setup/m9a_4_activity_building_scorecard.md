## Activity: Building a scorecard

**In this hands-on session, we will:**

- Turn two program questions into calculated indicators with thresholds
- Generate a results package that includes Indicator values
- Create the scorecard table in a project and read it with the group

*A scorecard is not a special page. It is a table of indicators by area, colored by rules that live in the indicator dictionary.*
