## Keeping the scorecard honest

- **Thresholds carry the message.** Decide them with the program and write down where they come from (national target, WHO benchmark, last year's median).
- **Direction matters.** A rate where lower is better (stillbirths, deaths) must be set to **Lower is better**, or the colors read backwards.
- **Check the Ledger before each package.** An indicator with missing months shows a misleading value, not an empty cell.
- **One rule per indicator, everywhere.** The same indicator is colored the same way on every scorecard in the instance. Change the rule in the dictionary, not on the chart.
- **Regenerate after every change.** New formula, new threshold, new population figure: nothing moves until the next results package.
