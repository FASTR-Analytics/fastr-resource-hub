## Creating your user folder

**I do:** Facilitator demonstrates logging into the platform, navigating to folders, and adding a new personal folder

**You do:**

1. Input your email and password
2. Enter the country project
3. Go to the **Slide Decks** tab → Click **+ New folder** → Type your name → Click **Save**
4. Go to the **Visualization** tab → Click **+ New folder** → Type your name → Click **Save**
