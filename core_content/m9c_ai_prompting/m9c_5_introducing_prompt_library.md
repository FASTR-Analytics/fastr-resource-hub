## Introducing the prompt library

The AI assistant includes a **prompt library** with ready-to-use prompts organized by workflow stage.

**How to access:** Click the three-dot menu in the AI Assistant panel → Select **Prompt library** → Browse and choose a prompt → Edit before using if needed

**How to use:** Each prompt is designed to be specific and purpose-driven. You can use them as-is or customize them for your context.
