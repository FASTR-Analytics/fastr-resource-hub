## Choosing the right chart type

![Choosing a chart type](../../resources/diagrams/chart_type_guide.svg)

| You want to know... | Use this |
|---------------------|----------|
| How is it changing over time? | Line chart |
| Which area is doing best or worst? | Bar chart |
| What are the exact numbers? | Table |
| Where is the pattern across many indicators or areas? | Heatmap |

*Most FASTR outputs use line charts for trends and heatmaps for comparisons. When in doubt, start with a line chart for one indicator or a heatmap for many.*
