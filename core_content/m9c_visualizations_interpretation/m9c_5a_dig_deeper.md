## Dig deeper: is it real or a data issue?

Look at 2-3 indicators for the **same region** over the same period. Ask yourself:

- Did all indicators drop together, or just one?
- If **only one dropped** — it may be a data issue (reporting gap, definition change) rather than a real disruption
- If **several dropped together** — it more likely reflects a real service disruption (staffing, supply, access)

*Cross-checking indicators helps you tell the difference between a data problem and a program problem.*
