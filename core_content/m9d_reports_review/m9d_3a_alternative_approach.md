## Alternative approach: Working without a custom prompt

**Use this approach when:**

- You have a previous report you are satisfied with
- You want to replicate a similar format for a new period
- No custom prompt is available for that report type

**Use a custom prompt when:**

- You have developed a clear plan for the report structure and content
- You feel comfortable building detailed instructions with the AI
- You want to fine-tune exactly how each slide is built

---

## Step 1: Upload the report to your Assets

1. Go to the main page and click **Assets** in the top menu
2. Click **Upload assets** and drag and drop the PDF file you want to use as a template

---

## Step 2: Include the report in your AI conversation

Once the file is in your Assets, you can attach it to any AI conversation so the AI can reference it.

1. Click the three-dot menu (⋮) in the top right of the AI panel
2. Select **Include file**
3. Choose the report file from the list
4. Click **Include selected**

Then ask the AI:

*"Use this report as a template. Create a similar report covering [time period]."*
