## Activity: Creating a disruption report with the AI Assistant

**Follow these steps to set up and launch the report generation. One team member takes the driver role.**

1. Open the **Slide Decks** tab in the FASTR platform
2. Click **+ Create slide deck** and give it a name (e.g., "Disruption Report for {country}")
3. Open the **AI Assistant** — if you are already in a conversation, start a new one
4. Open the **Prompt Library**, scroll to the bottom and select **"Prompt 1: FASTR Disruptions Report"** OR **"Prompt 4: Subnational Disruptions Report"**, depending on your use case
5. Review the prompt text that appears in the input field
