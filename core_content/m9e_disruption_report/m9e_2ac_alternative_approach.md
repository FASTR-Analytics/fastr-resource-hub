## Step 2: Include the report in your AI conversation

Once the file is in your Assets, you can attach it to any AI conversation so the AI can reference it.

1. Click the three-dot menu (⋮) in the top right of the AI panel
2. Select **Include file**
3. Choose the report file from the list
4. Click **Include selected**

Then ask the AI:

*"Use this report as a template. Create a similar report covering [time period]."*
