## Activity: Refine your disruption report


- [ ] Apply formatting to your report (fonts, colors, layout)
- [ ] Discuss your intended audience and adjust language accordingly
- [ ] Add additional sections for topics or subnational areas important for decision-makers

Once you have the core disruptions report, you can ask the AI to add more sections.

**For regional analysis:** Select prompt **"Standardized Report Generation - Prompt 2: Regional Disruptions Analysis"** from the prompt library. This generates one slide per region showing actual vs. expected service volumes (what was predicted based on past trends vs. what actually happened).

**For data quality assessment:** Select prompt **"Standardized Report Generation - Prompt 3: Data Quality Assessment"** from the prompt library. This adds an annex with Data Quality Assessment (DQA) visualizations and interpretation.

You can request one or both. The AI will append these sections to your report.
