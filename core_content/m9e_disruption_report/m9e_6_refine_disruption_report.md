## Activity: Refine your disruption report


- [ ] Apply formatting to your report (fonts, colors, layout)
- [ ] Discuss your intended audience and adjust language accordingly
- [ ] Add additional sections for topics or subnational areas important for decision-makers

Once you have the core disruptions report, you can ask the AI to add more sections.

**For regional analysis:** Select prompt **"Standardized Report Generation - Prompt 2: Regional Disruptions Analysis"** from the prompt library. This generates one slide per region showing actual vs. expected service volumes.

**For data quality assessment:** Select prompt **"Standardized Report Generation - Prompt 3: Data Quality Assessment"** from the prompt library. This adds an annex with DQA visualizations and interpretation.

You can request one or both. The AI will append these sections to your report.

## Review checklist: Prompt 2 & Prompt 3

**Prompt 2: Regional Analysis**

- [ ] Summary slide includes all subnational areas
- [ ] One slide per subnational area — none skipped
- [ ] Area names are spelled correctly
- [ ] Interpretations reference the correct area

**Prompt 3: Data Quality Assessment**

- [ ] Annex is numbered correctly (1 or 2)
- [ ] Completeness, outlier, and consistency slides present
- [ ] Color coding makes sense (green = good, red = concern)
- [ ] Low data quality areas or indicators are flagged

**Final:** Read through all interpretations as a team — does anything sound wrong or exaggerated?
