## Formatting cheatsheet

You can format your report text with **simple symbols**, the same way you'd write a message.

<div class="columns">

<div>

### Headings

- `#` Big title
- `##` Subtitle
- `###` Small heading

### Emphasis

- `*text*` → **bold**
- `-` at the start of a line → bullet
- Blank line between lines → spacing

</div>

<div>

### Tips

- Start every section with a clear heading
- One idea per paragraph
- Leave a blank line between paragraphs
- Prefer short sentences over long ones

</div>

</div>

> You don't have to learn HTML. These symbols cover 95% of cases — the AI can handle the rest.
