## How the Report Instructions File applies good prompting

| Checklist item | How the instructions file addresses it |
|----------------|----------------------------------------|
| **1. Clear purpose** | Specifies task: generate disruptions report slides |
| **2. Audience** | Implies MoH and policymakers through FASTR branding and cautious language |
| **3. Geography, time, scope** | Uses placeholders for country, dates; names all indicators (ANC, deliveries, vaccines, OPD) |
| **4. Interpretation guidance** | "Describe timing, duration, and magnitude"; treats findings as signals, not conclusions |
| **5. Output format** | Complete sentences, not bullets; slide layout defined (text left, visualization right) |
| **6. Guardrails** | "Cautious, analytical language"; "Do not present causal claims"; stay descriptive |

All you need to add is the country and time period.
