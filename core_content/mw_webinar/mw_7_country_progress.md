## FASTR across countries

Countries across Africa and beyond are using FASTR to strengthen routine health data analysis and improve program performance.

**What countries are doing with FASTR:**

- **Performance reviews** — Regular subnational reviews using FASTR outputs
- **Quarterly dashboards** — RMNCAH-N dashboards for program monitoring
- **Quality improvement** — Data quality plans driven by DQA findings
- **Resource allocation** — Evidence-based decisions on where to invest

Each country adapts the framework to their local context and priorities.
