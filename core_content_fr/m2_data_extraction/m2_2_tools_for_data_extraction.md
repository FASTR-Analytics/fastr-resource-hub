## Extraction des données

<div class="columns-image-right">
<div>

Nous proposons deux outils pour extraire les données du DHIS2 : un Data Downloader convivial et une fonction d'importation directe au sein de la plateforme FASTR.

Le Data Downloader fournit une interface simple pour parcourir et télécharger les données DHIS2. Il est particulièrement utile pour explorer quels indicateurs sont disponibles dans votre système et télécharger des données ventilées par catégories (par ex. par groupe d'âge ou par sexe).

Le Data Downloader est disponible à l'adresse : https://github.com/worldbank/DHIS2-Downloader/releases/
