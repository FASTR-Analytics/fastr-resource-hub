## Essayez par vous-même

Prenez un résultat FASTR que vous avez créé — un graphique, un tableau ou une heatmap.

- **Quel est le résultat ?** Décrivez ce que les chiffres montrent
- **Quel est l'enseignement clé ?** Écrivez le message principal en une phrase

*Un bon test : quelqu'un qui n'était pas dans la salle pourrait-il comprendre votre enseignement sans voir le graphique ?*
