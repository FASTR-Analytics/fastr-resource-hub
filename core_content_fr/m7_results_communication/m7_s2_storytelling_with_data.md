## Raconter une histoire avec les données

Traduire les données en récits convaincants qui guident la prise de décision.

### Éléments d'un récit de données

- **Intrigue** : À quelles questions les données répondent-elles ?
- **Contexte** : Quel est le contexte ?
- **Audience** : Qui a besoin d'entendre ce message ?
- **Problème** : Quel est le principal défi sanitaire ?
- **Implication** : Quelles actions ou recommandations en découlent ?

### Conseils
- Commencez par le message clé, pas par la méthodologie
- Utilisez des graphiques visuellement clairs — un message par visualisation
- Adaptez le récit à votre audience : un ministre a besoin d'un cadrage différent de celui d'un médecin chef de district
