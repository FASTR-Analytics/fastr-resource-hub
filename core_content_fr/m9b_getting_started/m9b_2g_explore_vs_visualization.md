## Explorer ou une visualisation ?

<div class="columns">
<div>

### Explorer

- Pour **regarder**
- Toutes les métriques, toutes les vues, d'un coup
- Des filtres seulement : pas de titre, pas de couleurs, pas de mise en page
- Rien n'est enregistré, c'est pareil pour tout le monde
- Ne peut pas aller dans une présentation ni un rapport

</div>
<div>

### Une visualisation

- Pour **garder et partager**
- Vous choisissez la métrique, les filtres, la forme
- A une ligne sur la page Produits, dans votre dossier
- Se copie dans les présentations et les rapports
- L'assistant IA peut la modifier

</div>
</div>

**La règle :** quand une vue d'Explorer répond à votre question, construisez-la comme visualisation. C'est le module suivant.
