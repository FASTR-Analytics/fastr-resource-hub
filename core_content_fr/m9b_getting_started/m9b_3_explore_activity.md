## Activité : jeter un premier regard avec Explorer

**Dans cette session pratique, vous allez :**

- Ouvrir **Explorer** dans la navigation latérale : toutes les analyses calculées, sans rien à créer
- Lire un indicateur dans le **Tableau**, puis le suivre **Dans le temps**, puis essayer la **Carte**
- Changer de module sous **Analyses complémentaires** (par exemple **Estimations de couverture**)
- Rapporter trois chiffres à la salle

*Document : Jeter un premier regard avec Explorer. Explorer sert à regarder ; une visualisation sert à garder et partager.*
