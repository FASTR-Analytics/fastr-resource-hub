## Approche alternative : Travailler sans prompt personnalisé

**Utilisez cette approche quand :**

- Vous avez un précédent rapport qui vous satisfait
- Vous souhaitez reproduire un format similaire pour une nouvelle période
- Aucun prompt personnalisé n'est disponible pour ce type de rapport

**Utilisez un prompt personnalisé quand :**

- Vous avez développé un plan clair pour la structure et le contenu du rapport
- Vous êtes à l'aise pour construire des instructions détaillées avec l'IA
- Vous voulez contrôler exactement comment chaque diapositive est construite
