## Activité : Affiner votre rapport de perturbations


- [ ] Appliquez la mise en forme à votre rapport (polices, couleurs, disposition)
- [ ] Discutez de votre public cible et adaptez le langage en conséquence
- [ ] Ajoutez des sections supplémentaires pour les sujets ou zones infranationales importants pour les décideurs

Une fois le rapport de perturbations de base prêt, vous pouvez demander à l'IA d'ajouter des sections supplémentaires.

**Pour l'analyse régionale :** Sélectionnez le prompt **"Standardized Report Generation - Prompt 2: Regional Disruptions Analysis"** dans la bibliothèque de prompts. Cela génère une diapositive par région montrant les volumes de services réels vs attendus (ce qui était prédit selon les tendances passées vs ce qui s'est réellement passé).

**Pour l'évaluation de la qualité des données :** Sélectionnez le prompt **"Standardized Report Generation - Prompt 3: Data Quality Assessment"** dans la bibliothèque de prompts. Cela ajoute une annexe avec des visualisations et une interprétation de l'Assurance Qualité des Données (AQD).

Vous pouvez demander l'un ou les deux. L'IA ajoutera ces sections à votre rapport.

## Liste de vérification : Prompt 2 & Prompt 3

**Prompt 2 : Analyse régionale**

- [ ] La diapositive de synthèse inclut toutes les zones infranationales
- [ ] Une diapositive par zone infranationale — aucune omise
- [ ] Les noms de zones sont correctement orthographiés
- [ ] Les interprétations font référence à la bonne zone

**Prompt 3 : Évaluation de la qualité des données**

- [ ] L'annexe est correctement numérotée (1 ou 2)
- [ ] Les diapositives de complétude, valeurs aberrantes et cohérence sont présentes
- [ ] Le code couleur est logique (vert = bon, rouge = préoccupation)
- [ ] Les zones ou indicateurs de faible qualité de données sont signalés

**Final :** Lisez toutes les interprétations en équipe — y a-t-il quelque chose qui semble faux ou exagéré ?
