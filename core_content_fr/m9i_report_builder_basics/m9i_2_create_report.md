## Étape 1 : Créer un rapport

<!-- PLACEHOLDER — screenshot de l'onglet Rapports + bouton Créer -->

1. Allez dans l'onglet **Rapports**
2. Cliquez sur **Créer un rapport**
3. Donnez un titre : « Suivi des perturbations — [Pays] — T4 2025 »

---

## Étape 2 : Ajouter une diapositive

<!-- PLACEHOLDER — screenshot de l'interface d'ajout de diapositive -->

1. Cliquez sur **Ajouter une diapositive**
2. Sélectionnez les visualisations à inclure (graphiques de perturbation, couverture, etc.)
3. Regroupez les indicateurs qui racontent la même histoire

**Exemple** : les méthodes contraceptives longue et courte durée ensemble, car elles montrent la même tendance de baisse.

---

## Étape 3 : Rédiger l'interprétation

Pour chaque diapositive, vous devez écrire :

**1. Le titre** — le message principal en une phrase

> *Baisse prolongée des méthodes contraceptives, surtout pour les courtes durées d'action*

**2. Le texte d'interprétation** — décrivez :
- Ce que vous **voyez** dans les graphiques (tendances, chiffres)
- Ce que cela **signifie** pour le programme
- Les **questions** que cela soulève

**Conseil** : regardez les zones rouges et vertes. Les zones rouges = volumes en dessous des attentes. Commencez par là.

---

## Comment écrire un bon titre de diapositive

Le titre doit être un **constat**, pas une description. Comparez :

| | Titre |
|---|-------|
| ❌ | Résultats CPN1, CPN4 et CPN1 précoce |
| ✅ | Les CPN1 restent stables, mais les CPN4 affichent un déficit persistant |

Le lecteur doit comprendre le message **sans lire le reste de la diapositive**.
