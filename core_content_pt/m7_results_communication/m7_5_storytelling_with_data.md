## Contar histórias com dados

A narração de histórias traduz dados e visualizações em narrativas convincentes que orientam a tomada de decisões.

**Elementos de uma história de dados:**

| Elemento | Descrição |
|---------|-------------|
| **Plot** | Que perguntas serão respondidas com os dados? |
| **Setting** | Qual é o contexto? |
| A quem está a contar esta história? |
| Qual é o principal problema de saúde ou descoberta? |
| Que acções ou recomendações se seguem? |

**Lembre-se: A história não é apenas *o que* os dados mostram, mas *por que é importante* e *o que fazer sobre isso*.
