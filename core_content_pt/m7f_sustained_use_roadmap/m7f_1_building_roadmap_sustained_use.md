## Construir um roteiro para uma utilização sustentada

Ligar resultados individuais a acções é o primeiro passo. Um roteiro transforma isso num hábito - passando de uma análise pontual para uma **utilização rotineira dos dados**.

**Principais componentes de um roteiro de sustentabilidade:**

| Componente | Perguntas a responder |
|-----------|-------------------|
| Frequência** | Com que frequência irá atualizar e divulgar as análises? (Trimestralmente?) |
| Responsabilidade** | Quem carrega os dados? Quem cria os relatórios? Quem apresenta? |
| Integração de plataformas** | Quais as reuniões/fóruns existentes que irá utilizar? (TWG da RMNCAH-N, revisões dos CSP?)
| Garantia de qualidade** | Quem revê os resultados antes da divulgação? |
| Como irá verificar se os dados estão a ser utilizados para tomar decisões? |

**Objetivo: O FASTR torna-se parte da rotina de M&A e não um projeto especial.
