## Prática: adicionar indicadores em equipa

Preparámos uma folha de cálculo com indicadores do DHIS2 já identificados e selecionados para a plataforma, os que precisa para reproduzir os seus relatórios e boletins. Tem um separador por grupo de trabalho.

**Como vamos trabalhar: um ecrã de cada vez.** Para evitar duplicados, os indicadores são adicionados a partir de um único computador, com o ecrã partilhado, e cada grupo tem a sua vez.

1. **À vez**: o facilitador partilha o ecrã; cada grupo lidera por sua vez
2. **Adicione os seus indicadores**: abra o separador do seu grupo, adicione os indicadores atribuídos como mostrado, depois passe a vez
3. **Uma única importação**: quando todos os grupos terminarem, corra uma importação DHIS2 a partir deste computador e depois gere um pacote de resultados
