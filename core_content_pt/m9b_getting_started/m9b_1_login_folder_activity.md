## Atividade: Entrar na plataforma e criar uma pasta para si

**O que vais aprender
Onde se chega quando se entra na plataforma, como encontrar o projeto do seu país e porque é que uma pasta pessoal mantém o seu trabalho acessível durante o resto do workshop.

**O que vai praticar
- Iniciar sessão na plataforma FASTR
- Abra o projeto do seu país (ou o projeto de demonstração)
- Crie uma pasta com o seu nome em **Visualizações** e **Desenhos de slides**
