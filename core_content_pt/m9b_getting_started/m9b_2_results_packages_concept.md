## De onde vêm os números de um projeto

**Os dados vivem ao nível da instância.** Os administradores importam-nos do DHIS2, uma vez para todo o país.

**As análises são calculadas num pacote de resultados.** Um administrador seleciona os módulos de análise e gera um pacote — um conjunto versionado de resultados já calculados.

**O seu projeto lê um pacote.** Cada gráfico, tabela e relatório do projeto assenta no pacote que lhe está anexado.

- Um novo mês de dados? → novo pacote → os projetos mudam para ele
- O separador **Pacote de resultados** do projeto mostra que pacote está em uso e a sua data
- Marque **«Usar sempre o pacote fixado da instância»** e o seu projeto segue automaticamente o pacote de referência
