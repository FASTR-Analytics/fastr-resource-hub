## Abordagem alternativa: Trabalhar sem um prompt personalizado

**Utilize esta abordagem quando:**

- Tem um relatório anterior com o qual está satisfeito
- Deseja replicar um formato semelhante para um novo período
- Não há nenhuma solicitação personalizada disponível para esse tipo de relatório

**Utilizar um prompt personalizado quando:**

- Desenvolveu um plano claro para a estrutura e o conteúdo do relatório
- Se sente à vontade para criar instruções detalhadas com a IA
- Pretende ajustar exatamente a forma como cada diapositivo é construído
