## Porquê FASTR?

Muitos países enfrentam desafios comuns com os dados de saúde:

- **Dados recolhidos mas subutilizados** - Os dados de rotina ficam no DHIS2 sem orientar as decisões
- **Ciclos analíticos lentos** - As revisões anuais perdem oportunidades de ação atempada
- **Fontes de dados fragmentadas** - HMIS, inquéritos e avaliações de estabelecimentos analisados em silos

**O FASTR aborda esta questão** fornecendo aos países ferramentas e métodos para uma análise rápida e de rotina de múltiplas fontes de dados - transformando os dados em decisões atempadas para sistemas de CSP mais fortes.
