## Abordagem FASTR para a monitorização do RMNCAH-N

**Análise trimestral dos dados do DHIS2**, centrada nos indicadores prioritários nacionais:

- **Construir ferramentas sustentáveis** para que as partes interessadas possam gerar as análises e visualizações corretas, no momento certo, sobre os seus indicadores de interesse
- **Combinar a análise com o reforço de capacidades** para sustentabilidade e institucionalização

### Triangulação de dados

Os dados do DHIS2 e das unidades sanitárias devem ser **integrados** para responder a perguntas-chave:
- A análise do DHIS2 responde a perguntas sobre **resultados trimestrais** (cobertura, tendências)
- Os inquéritos telefónicos às unidades sanitárias aprofundam o **"porquê "** (prontidão, qualidade)
- Os inquéritos aos agregados familiares acrescentam dados do lado da **procura** (acesso, experiência)
