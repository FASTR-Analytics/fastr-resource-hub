# data_received/

Reference materials received from partners — checklists, translated drafts,
indicator sheets, and external guidance. **Inputs**, not curriculum content.

Nothing here is rendered into slides, handouts, or the docs site directly.
These files are consulted when writing or updating methodology content; if a
finding from a document here needs to land in the curriculum, encode it in
`methodology/` (and the FR mirror) and cite the source there.

Examples of what lives here:

- FASTR data prep checklists from country teams (`.xlsx`)
- Translated FASTR prompts (`.docx`)
- GFF Measurement Framework indicator reference sheets (`.pdf`)
- External writing guides (e.g. LLM writing guidance)

When adding a new file, give it a descriptive name (no timestamps in
filenames — use git history for dates) and prefer Markdown or PDF for things
that need to be readable in the browser.
