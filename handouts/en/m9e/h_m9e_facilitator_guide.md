# Facilitator guide — Disruption Report

<p class="meta-line"><strong>Facilitator guide</strong> · <strong>Disruption Report</strong></p>

## About this activity

Teams produce a full **disruption report with the AI Assistant**, then verify, refine, and peer-review it. It's the capstone of the analysis activities: it assumes participants have built a report by hand (manual reports) and practised prompting.

**Four participant handouts.** **~180–240 min** — the longest activity. Teams work in small groups with one **driver** at the keyboard.

## How to run it

- **Prerequisites:** participants should have done the manual report build and the prompting activity first. If they haven't, slow down on the prompt step.
- **Group setup:** one driver per team; everyone else reviews. Rotate the driver between sections if you can.
- **Demo the first prompt run live** before teams start — show the Prompt Library, running Prompt 1, and answering the AI's questions.
- **Budget for generation time:** the AI takes 5–10 min per build. Use that gap for the verify checklist discussion.
- The through-line: the AI drafts, the team is accountable. Reinforce verification at every step.

## The activities

### 1. Create the report with the AI

**Activity · ~60 min**

**What it is** — teams generate the core report from a ready-made prompt (Prompt 1 national, or Prompt 4 subnational).
**What the handout covers** — create the deck → open the AI Assistant → pick the prompt → answer its questions (period, subtitle, groupings, mortality) → review groupings → confirm → let it build.
**Watch for** — teams clicking a slide mid-generation (it interrupts the build) — tell them to wait. Spend real time on the **groupings** step; a rushed grouping produces a messy report. The driver should type answers, not the whole group at once.

### 2. Verify the output

**Activity · ~20 min**

**What it is** — a two-part checklist read by the whole team before the report is used.
**What the handout covers** — general checks (all slides, country, period, no placeholders) and report checks (groupings, charts loading, interpretations match charts, titles are findings).
**Watch for** — teams trusting the AI because it sounds confident. Make them read interpretations **aloud** and check the words against the chart.

### 3. Refine

**Activity · ~40 min**

**What it is** — formatting + optional extra sections via Prompt 2 (regional) and Prompt 3 (data quality).
**What the handout covers** — polish for the audience, append regional/DQA sections, check each new section.
**Watch for** — teams adding every section "to be safe". Add only what a decision-maker needs.

### 4. Peer review and present

**Activity · ~40 min**

**What it is** — teams swap reports, review as a fresh reader, and present feedback.
**What the handout covers** — read cold (clear message? a decision-maker would act?), 2 strengths + 2 suggestions, present back, group discussion.
**Watch for** — vague feedback. Push for specific, actionable suggestions tied to a slide.
