# Formatting cheatsheet — editing report text

<p class="meta-line"><strong>Reference</strong> · <strong>Disruption Report</strong> · <strong>~5 min</strong></p>

<div class="p1-grid">
<aside class="p1-sidebar">

<p class="sb-label">What this handout is</p>

A one-page reference for editing slide text in the FASTR report builder. You format text using a few simple symbols — the same way you would write a quick message.

You do not need to learn HTML. These symbols cover 95% of cases — the AI can handle the rest.

</aside>
<div class="p1-main">

## Headings

| Symbol | What it does |
|--------|--------------|
| `#` Title | Big title |
| `##` Subtitle | Subtitle |
| `###` Small heading | Small heading |

## Emphasis and lists

| Symbol | What it does |
|--------|--------------|
| `**text**` | **Bold** |
| `*text*` | *Italic* |
| `-` at the start of a line | Bullet |
| Blank line between paragraphs | Spacing |

## Writing tips

- Start every section with a clear heading
- One idea per paragraph
- Leave a blank line between paragraphs
- Prefer short sentences over long ones
- Keep the lead sentence punchy — the title carries the finding, the lead supports it

## When you get stuck

If a layout will not behave, ask the AI directly: *"Reformat this paragraph using the same style as slide 4."* The AI knows the report builder's conventions and can handle the symbols for you.
