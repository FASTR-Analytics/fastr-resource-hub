# Facilitator guide — Prompting Techniques

<p class="meta-line"><strong>Facilitator guide</strong> · <strong>Prompting Techniques</strong> · <strong>NOT FOR DISTRIBUTION</strong></p>

## About these activities

Prompting Techniques builds the skill of **asking the AI well**. It moves from a single clear prompt, through exploration and comparing approaches, to refining and verifying — the foundation for every AI-assisted activity later in the workshop.

**Six handouts.** **~115 min** of participant time.

## How to run it

- Handout 1, **build a clear prompt**, is the foundation — don't skip it. Everything else assumes it.
- Most of these are platform activities: demo briefly, then participants follow the handout.
- Handout 4 is **solo** work; the rest suit pairs or teams.
- The mindset to instil: a good prompt is rarely the first one written. Refining is the skill, not a failure.

## The activities

### 1. Build a clear prompt

**Activity · ~15 min**

**What it is** — a foundation activity: four questions to answer before writing any prompt.
**What the handout covers** — a what / who / scope / success worksheet, then writing a prompt from those answers.
**Watch for** — participants want one perfect prompt. Stress that refining is normal — the four questions just produce a stronger *first* message.

### 2. Explore with the AI Assistant

**Activity · ~20 min**

**What it is** — a hands-on activity: test a prompt on the platform, vary one thing, ask a follow-up.
**What the handout covers** — a base prompt, a one-variable change, a follow-up question; save what's useful.
**Watch for** — participants change two things at once. One variable at a time — observe, then change the next.

### 3. Iterative vs single prompt

**Activity · ~30 min**

**What it is** — a comparison activity: build the same 3-slide report two ways.
**What the handout covers** — Exercise A (four iterative prompts), Exercise B (one structured prompt), a reflection, and a when-to-use-each table.
**Watch for** — participants treat one approach as "better". Both are valid — the point is to match the approach to the task.

### 4. Refine your prompt (solo)

**Activity · ~20 min**

**What it is** — a solo exercise tightening one prompt over three rounds.
**What the handout covers** — pick one topic, run three rounds (start simple, add context, make it actionable), each in a fresh conversation, then reflect.
**Watch for** — participants don't notice *why* the last prompt worked. Push them to name what each round added — where/when, then why/who.

### 5. Use a previous report as a template

**Activity · ~10 min**

**What it is** — a hands-on activity guiding the AI from an example you already trust.
**What the handout covers** — upload a previous report to Resources, include it in the AI conversation, ask the AI to reproduce the structure.
**Watch for** — even with a template the AI can drift. Participants must compare the output side-by-side with the model before sharing.

### 6. Verify the AI's output

**Activity · ~20 min**

**What it is** — a hands-on verification activity: a repeatable check before delivering AI-generated text.
**What the handout covers** — read and mark claims, triage by risk, hand-check high-risk claims, AI-check medium-risk, a final consistency scan.
**Watch for** — participants rush this; it needs the full 20 minutes. The rule to leave them with: *if you wouldn't sign it, it isn't finished.*

## Wrapping up

Verification (Activity 6) is the note to end on. Prompting well gets a fast draft; verifying well is what makes it the participant's own work.
