# Refine your prompt (self-paced)

<p class="meta-line"><strong>Activity</strong> · <strong>Prompting techniques</strong> · <strong>~20 min</strong></p>

<div class="p1-grid">
<aside class="p1-sidebar">

<p class="sb-label">Before you start</p>

- ☐ You've completed **Build a clear prompt**, **Explore with the AI Assistant**, and **Iterative vs single-prompt**
- ☐ The AI Assistant is open in your country's project

<p class="sb-label">Why it matters</p>

A good prompt is rarely the first one you write. This exercise walks through three rounds on one topic — each round adds something specific.

</aside>
<div class="p1-main">

## How to do this

Pick **one** topic from your data and stay with it for all three rounds:

- ☐ Outliers
- ☐ Completeness
- ☐ Disruptions

Run each round in a **new** AI conversation so you see the difference from a clean slate, not as a follow-up.

## Three rounds

| Round | Prompt to try | Ask yourself after the AI responds |
|-------|---------------|------------------------------------|
| **1. Start simple** | *Create a slide about [your topic].* | What did the AI include? Would this work in a real meeting? |
| **2. Add context** | *Create a slide about [topic] for a [meeting type]. Show [specific data]. Explain which regions have the most issues.* | Is it more specific? Does it identify priorities? |
| **3. Make it actionable** | *Create a slide about [topic] for [meeting]. Compare areas — which need support? Suggest possible reasons.* | Does it prioritize areas? Point toward next steps? |

## Reflection

After all three rounds:

- Which round produced the most useful slide?
- What specifically made the final prompt more effective than the first?
- If you ran this prompt again next week, which version would you save and reuse?

## Tips

> **The pattern is "what / where / when / why / who".** Round 2 typically adds *where* and *when*. Round 3 adds *why* (purpose) and *who* (audience). The first round is missing all of these.

> **Save the best prompt.** Once you find a phrasing that works well, save it (or add it to your team's prompt library — see the next section) so you don't rebuild it from scratch.
