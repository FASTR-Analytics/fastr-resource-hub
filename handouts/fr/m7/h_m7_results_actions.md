# Reliez vos résultats aux actions

<p class="meta-line"><strong>Activité</strong> · <strong>Communication des résultats</strong> · <strong>~20 min</strong></p>

## Avant de commencer

- ☐ Vous avez **au moins trois constats** de votre analyse FASTR rédigés (énoncés de constat de l'activité précédente)
- ☐ Vous avez réfléchi à votre audience (activité de cartographie)
- ☐ Une équipe pays partenaire est disponible pour vous donner un retour à la fin

## Pourquoi c'est important

Un constat n'est qu'une observation tant que personne *n'agit* dessus. Le but de cette activité est de rendre chaque constat **actionnable** — en nommant un décideur précis, une prochaine étape concrète, et un calendrier réaliste.

Un constat sans décideur dérive. Un constat avec « le ministère » comme décideur est trop vague pour dériver vers qui que ce soit en particulier. Un constat avec « Directeur des SSP, d'ici la fin du trimestre prochain » est suivi.

## La feuille de travail

Pour vos **3 principaux constats**, remplissez ce tableau :

| Constat | Qui doit savoir ? | Quelle décision / action ? | Pour quand ? |
|---------|-------------------|----------------------------|--------------|
| 1. |  |  |  |
| 2. |  |  |  |
| 3. |  |  |  |

## Conseils — soyez précis

> **Spécifique à une personne, une action, une date.** Les entrées vagues meurent dans les boîtes mail ; les spécifiques sont suivies.

- **« Qui doit savoir ? »** — *pas* « le ministère », *plutôt* « Directeur des SSP » ou « Responsable des programmes de santé au MdS de l'État ».
- **« Quelle décision / action ? »** — *pas* « améliorer la performance », *plutôt* « organiser des visites de supervision formative dans le District X le trimestre prochain ».
- **« Pour quand ? »** — une vraie date, pas « bientôt ». Reliez-la à une réunion ou un cycle existant si possible.

## Exemple

| Constat | Qui ? | Quoi ? | Pour quand ? |
|---------|-------|--------|--------------|
| CPN1 a chuté de 18 % dans la Région Nord au T1 2026 vs T1 2025 | Directeur des SSP, MdS | Briefer le Directeur sur le constat + recommander des visites de supervision formative dans 3 districts avec les plus fortes baisses | Avant la prochaine réunion de direction (15 juin) |
| Complétude Penta1 < 60 % dans 4 districts | Responsable des données, MdS de l'État | Planifier un atelier qualité des données avec les 4 districts pour identifier les goulets d'étranglement de notification | Fin du T2 (30 juin) |
| Couverture BCG supérieure à 100 % dans 2 districts | Responsable de la surveillance | Investiguer le dénominateur (l'estimation de population peut être obsolète) | Avant la prochaine revue trimestrielle |

Remarquez : chaque ligne nomme une personne, une action concrète, une date.

## Pièges à éviter

- **« Partager avec les parties prenantes »** n'est pas une action. Les parties prenantes sont plurielles et vagues. Choisissez une partie prenante, donnez-lui une demande.
- **« Améliorer la qualité des données »** n'est pas une action. Choisissez une intervention spécifique (formation, supervision, correction système) et une cible.
- **« Dès que possible »** n'est pas un calendrier. Si vous ne pouvez pas le lier à une date, l'action n'est pas encore réelle.

## Revue par les pairs

Échangez votre feuille avec une autre équipe pays. Demandez-leur :

- Les décideurs sont-ils précis (une personne, pas un groupe) ?
- Les actions sont-elles concrètes (quelque chose dont vous pouvez vérifier l'exécution) ?
- Les calendriers sont-ils réalistes dans le contexte du pays ?
- Quelle est la ligne la plus faible, et pourquoi ?

## Étape suivante

Les constats reliés à des actions alimentent directement votre **plan d'action pays** — la prochaine activité. Vous prendrez cette liste et la transformerez en un rythme trimestriel durable.
