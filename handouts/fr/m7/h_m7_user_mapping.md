# Cartographiez vos utilisateurs

<p class="meta-line"><strong>Activité</strong> · <strong>Communication des résultats</strong> · <strong>~20 min</strong></p>

## Avant de commencer

- ☐ Vous travaillez avec votre équipe pays (c'est une activité de discussion)
- ☐ Vous avez en tête une sortie FASTR récente (un graphique, un rapport, une présentation) que vous prévoyez de partager

## Pourquoi c'est important

La même analyse résonne très différemment selon qui se trouve dans la salle. Un Directeur des SSP veut le message clé et une décision ; un analyste de district veut les données sous-jacentes. Cartographier votre audience avant de communiquer **change ce que vous dites, combien de temps vous prenez, et ce que vous coupez**.

## La feuille de travail

Remplissez ceci pour **une audience spécifique** à laquelle vous vous adressez — pas « tout le monde ».

| Question | Votre réponse |
|----------|---------------|
| Qui est l'utilisateur final principal de vos produits FASTR ? | |
| Quelle décision ou action prendra-t-il sur la base de ces données ? | |
| Quelles sont les 2-3 informations qui l'intéressent le plus ? | |
| Quel format / quelle durée fonctionne le mieux pour cette audience ? | |
| Quand et où allez-vous présenter à cette audience ? | |

## Exemple

Avant de remplir votre feuille, voici à quoi ressemble une réponse complétée :

| Question | Exemple de réponse |
|----------|--------------------|
| Qui ? | **Directeur des Soins de Santé Primaires, MdS** |
| Décision ? | **Où déployer les visites de supervision formative ce trimestre** |
| 2-3 choses qui l'intéressent ? | **(1) Quels districts ont eu la plus grande baisse de CPN1 le trimestre dernier, (2) Si la baisse est réelle ou un problème de données, (3) Action recommandée** |
| Format / durée ? | **Une note d'une page + 5 min de présentation orale** |
| Quand / où ? | **Réunion mensuelle de la direction, deuxième mardi du mois** |

Remarquez : la réponse à « ce qui l'intéresse » est **spécifique** — pas « la qualité des données » mais une question concrète avec une prochaine étape réelle.

## Conseils

> **Spécifique vaut mieux que complet.** Un directeur a rarement besoin de tous les graphiques. Il a besoin d'un graphique qui appelle une décision.

- Si votre réponse à « décision ou action » est vague (p. ex. « améliorer la performance »), vous ne connaissez pas encore assez bien l'audience. Parlez-lui.
- Différentes audiences = différentes sorties à partir de la même analyse. Cartographiez chaque audience séparément.

## Partage avec le groupe

Après ~15 min de discussion en équipe, **partagez un aperçu** sur votre audience avec le grand groupe — quelque chose que vous avez réalisé et que vous n'aviez pas vu avant de la cartographier.

## Étape suivante

Les prochaines activités vous aideront à **construire le message** pour cette audience : rédiger des énoncés de constat, relier les résultats aux actions, et planifier la diffusion.
