# Configurer les paramètres de votre rapport

<p class="meta-line"><strong>Activité</strong> · <strong>Présentations</strong> · <strong>~10 min</strong></p>

<div class="p1-grid">
<aside class="p1-sidebar">

<p class="sb-label">Avant de commencer</p>

- ☐ Votre présentation contient au moins une diapositive de contenu finalisée
- ☐ La présentation est ouverte et vous voyez le panneau **Paramètres** dans la vue rapport

<p class="sb-label">Pourquoi c'est important</p>

Les paramètres font passer un brouillon à un rapport partageable. Un nom clair, un style cohérent, les bons logos et des numéros de page : une présentation privée devient quelque chose qu'un collègue ou un partenaire peut ouvrir sans poser de questions.

</aside>
<div class="p1-main">

## Que régler

Ouvrez le panneau **Paramètres** et parcourez ces cinq sections dans l'ordre.

<h2 class="step-h"><span class="step-n">1</span><span>Général</span></h2>

Mettez à jour le nom du rapport. Utilisez la convention décidée par votre équipe (pays, période, sujet, votre nom).

<h2 class="step-h"><span class="step-n">2</span><span>Style</span></h2>

Choisissez la couleur des diapositives et ajustez les détails de l'arrière-plan. Gardez la même option sur toute la présentation.

<h2 class="step-h"><span class="step-n">3</span><span>Logos</span></h2>

Ajoutez les logos que votre public s'attend à voir. Utilisez les ressources téléversées dans le projet.

<h2 class="step-h"><span class="step-n">4</span><span>Détails de page</span></h2>

Activez les numéros de page si la présentation va être imprimée ou partagée en PDF.

<h2 class="step-h"><span class="step-n">5</span><span>Enregistrer</span></h2>

Toujours enregistrer avant de quitter le panneau. Les paramètres ne s'enregistrent pas automatiquement comme le contenu des diapositives.

</div>
</div>

## Point de contrôle

À la fermeture du panneau Paramètres, votre présentation doit :

- Avoir un nom clair que votre équipe peut retrouver
- Utiliser un schéma de couleurs cohérent sur toutes les diapositives
- Afficher les logos attendus
- Afficher les numéros de page si la présentation va être imprimée ou partagée en PDF

## Supprimer le rapport

Les paramètres contiennent aussi le bouton **Supprimer le rapport**. Utilisez-le pour retirer les brouillons ou les présentations de test d'un projet. La suppression est définitive, donc vérifiez le nom du rapport deux fois avant de confirmer.

## Ce qui peut mal se passer

- **Les changements n'apparaissent pas sur la diapositive** — vous avez oublié d'enregistrer. Rouvrez Paramètres et confirmez.
- **Logos manquants** — les fichiers de logos n'ont pas été téléversés dans les ressources du projet. Ajoutez-les dans Ressources, puis revenez aux Paramètres.
> 🔎 **Vérifier dans votre interface actuelle** : la disposition du panneau Paramètres peut varier légèrement. Les sections ci-dessus s'appliquent quoi qu'il en soit.

## Et ensuite

La présentation est prête à être partagée. Le module suivant couvre l'export et la diffusion.
