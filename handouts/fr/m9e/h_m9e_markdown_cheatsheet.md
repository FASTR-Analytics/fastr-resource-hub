# Aide-mémoire de mise en forme — éditer le texte du rapport

<p class="meta-line"><strong>Référence</strong> · <strong>Rapport de perturbations</strong> · <strong>~5 min</strong></p>

<div class="p1-grid">
<aside class="p1-sidebar">

<p class="sb-label">À quoi sert cet aide-mémoire</p>

Une référence d'une page pour éditer le texte des diapositives dans le constructeur de rapports FASTR. Vous mettez en forme le texte avec quelques symboles simples — comme si vous écriviez un message rapide.

Pas besoin d'apprendre HTML. Ces symboles suffisent pour 95 % des cas — l'IA peut s'occuper du reste.

</aside>
<div class="p1-main">

## Titres

| Symbole | Ce que ça fait |
|--------|--------------|
| `#` Titre | Grand titre |
| `##` Sous-titre | Sous-titre |
| `###` Petit titre | Petit titre |

## Mise en forme et listes

| Symbole | Ce que ça fait |
|--------|--------------|
| `**texte**` | **Gras** |
| `*texte*` | *Italique* |
| `-` au début d'une ligne | Puce |
| Ligne vide entre paragraphes | Espacement |

## Conseils d'écriture

- Commencez chaque section par un titre clair
- Une idée par paragraphe
- Laissez une ligne vide entre paragraphes
- Préférez plusieurs courtes phrases à une longue
- Gardez la phrase d'accroche percutante — le titre porte le constat, la phrase d'accroche le soutient

## Quand vous bloquez

Si une mise en page ne se comporte pas comme prévu, demandez directement à l'IA : *« Reformate ce paragraphe avec le même style que la diapositive 4. »* L'IA connaît les conventions du constructeur de rapports et peut s'occuper des symboles pour vous.
