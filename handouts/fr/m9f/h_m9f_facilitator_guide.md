# Guide du facilitateur — Techniques de prompting

<p class="meta-line"><strong>Guide du facilitateur</strong> · <strong>Techniques de prompting</strong></p>

## À propos de ces activités

Techniques de prompting construit la compétence de **bien demander à l'IA**. Il part d'un prompt clair unique, passe par l'exploration et la comparaison d'approches, jusqu'à l'affinage et la vérification — la base de toutes les activités assistées par l'IA plus loin dans l'atelier.

**Six documents.** **~115 min** de temps participant.

## Comment l'animer

- Le document 1, **construire un prompt clair**, est la base — ne le sautez pas. Tout le reste le présuppose.
- La plupart sont des activités sur la plateforme : démontrez brièvement, puis les participants suivent le document.
- Le document 4 est un travail **en individuel** ; les autres conviennent aux binômes ou aux équipes.
- L'état d'esprit à transmettre : un bon prompt est rarement le premier écrit. Affiner est la compétence, pas un échec.

## Les activités

### 1. Construire un prompt clair

**Activité · ~15 min**

**Ce que c'est** — une activité de fondation : quatre questions à se poser avant d'écrire un prompt.
**Ce que couvre le document** — une feuille de travail quoi / qui / portée / succès, puis l'écriture d'un prompt à partir de ces réponses.
**À surveiller** — les participants veulent un prompt parfait du premier coup. Insistez : affiner est normal — les quatre questions produisent juste un *premier* message plus solide.

### 2. Explorer avec l'Assistant IA

**Activité · ~20 min**

**Ce que c'est** — une activité pratique : tester un prompt sur la plateforme, varier un élément, poser une question de suivi.
**Ce que couvre le document** — un prompt de base, une modification d'une variable, une question de suivi ; enregistrer ce qui est utile.
**À surveiller** — les participants changent deux choses à la fois. Une variable à la fois — observer, puis changer la suivante.

### 3. Itératif vs prompt unique

**Activité · ~30 min**

**Ce que c'est** — une activité de comparaison : construire le même rapport de 3 diapositives de deux façons.
**Ce que couvre le document** — l'Exercice A (quatre prompts itératifs), l'Exercice B (un prompt structuré unique), une réflexion, et un tableau quand-utiliser-chaque.
**À surveiller** — les participants traitent une approche comme « meilleure ». Les deux sont valables — l'enjeu est d'adapter l'approche à la tâche.

### 4. Affiner votre prompt (en autonomie)

**Activité · ~20 min**

**Ce que c'est** — un exercice en autonomie qui resserre un prompt en trois rondes.
**Ce que couvre le document** — choisir un sujet, mener trois rondes (commencer simple, ajouter du contexte, rendre actionnable), chacune dans une nouvelle conversation, puis réfléchir.
**À surveiller** — les participants ne remarquent pas *pourquoi* le dernier prompt a marché. Poussez-les à nommer ce que chaque ronde a ajouté — où/quand, puis pourquoi/qui.

### 5. Utiliser un rapport précédent comme modèle

**Activité · ~10 min**

**Ce que c'est** — une activité pratique pour guider l'IA à partir d'un exemple en lequel vous avez déjà confiance.
**Ce que couvre le document** — téléverser un rapport précédent dans Ressources, l'inclure dans la conversation IA, demander à l'IA de reproduire la structure.
**À surveiller** — même avec un modèle, l'IA peut dériver. Les participants doivent comparer la sortie côte à côte avec le modèle avant de partager.

### 6. Vérifier la sortie de l'IA

**Activité · ~20 min**

**Ce que c'est** — une activité pratique de vérification : un contrôle reproductible avant de livrer un texte généré par l'IA.
**Ce que couvre le document** — lire et marquer les affirmations, trier par risque, vérifier à la main les affirmations à risque élevé, vérifier avec l'IA celles à risque moyen, un scan final de cohérence.
**À surveiller** — les participants bâclent cette étape ; elle a besoin des 20 minutes complètes. La règle à leur laisser : *si vous ne le signeriez pas, ce n'est pas fini.*

## Pour conclure

La vérification (activité 6) est la note sur laquelle finir. Bien prompter donne un brouillon rapide ; bien vérifier est ce qui en fait le travail propre du participant.
