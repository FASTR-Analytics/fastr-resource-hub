# Folha de formatação — editar o texto do relatório

<p class="meta-line"><strong>Referência</strong> · <strong>Relatório de perturbações</strong> · <strong>~5 min</strong></p>

<div class="p1-grid">
<aside class="p1-sidebar">

<p class="sb-label">O que é este folheto</p>

Uma referência de uma página para editar o texto dos diapositivos no construtor de relatórios FASTR. Formata o texto com alguns símbolos simples — da mesma forma que escreveria uma mensagem rápida.

Não precisa de aprender HTML. Estes símbolos cobrem 95 % dos casos — a IA pode tratar do resto.

</aside>
<div class="p1-main">

## Títulos

| Símbolo | O que faz |
|--------|--------------|
| `#` Título | Título grande |
| `##` Subtítulo | Subtítulo |
| `###` Título pequeno | Título pequeno |

## Ênfase e listas

| Símbolo | O que faz |
|--------|--------------|
| `**texto**` | **Negrito** |
| `*texto*` | *Itálico* |
| `-` no início de uma linha | Marcador |
| Linha em branco entre parágrafos | Espaçamento |

## Dicas de escrita

- Comece cada secção com um título claro
- Uma ideia por parágrafo
- Deixe uma linha em branco entre parágrafos
- Prefira frases curtas a frases longas
- Mantenha a frase de abertura concisa — o título carrega o achado, a abertura sustenta-o

## Quando ficar parada

Se um esquema não se comportar bem, peça diretamente à IA: *«Reformata este parágrafo no mesmo estilo do diapositivo 4.»* A IA conhece as convenções do construtor de relatórios e pode tratar dos símbolos por si.
