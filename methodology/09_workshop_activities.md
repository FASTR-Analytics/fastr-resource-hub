## Explore with the AI Assistant

Follow these three steps. You can type or copy the prompts exactly as shown.

**1. Try this prompt**

> Show ANC1 service utilization by region over the last 12 months

This works because it tells the AI: **What** (ANC1), **Where** (by region), **When** (last 12 months)

**2. Now change one thing**

- **Change the indicator:** Show BCG dose by region over the last 12 months
- **Change the time:** Show ANC1 by region for 2023 and 2024
- **Change the level:** Show ANC1 by district over the last 12 months

Pick one and try it. Notice how changing one word changes the output.

**3. Ask a follow-up** — Show this as a bar chart / Which region had the biggest change? / Add Penta1 to the comparison

Save any visualizations you like to your own folder.

## How to interpret a FASTR visualization

A step-by-step framework for reading any figure:

| Step | Question |
|------|----------|
| **1. What indicator?** | Identify the health indicator or metric being shown |
| **2. What level & period?** | Note the geographic level and the time period covered |
| **3. What is being compared?** | Actual vs. expected? Districts vs. each other? Changes over time? |
| **4. Read the values** | What are the magnitudes? Are they high, low, or changing? |
| **5. What stands out?** | Identify trends, gaps, spikes, disruptions, or anomalies |
| **6. So what?** | What does this mean for service delivery? What action does it suggest? |

*Tip: Always check the legend, axis labels, and any footnotes before interpreting.*

## Introducing the prompt library

The AI assistant includes a **prompt library** with ready-to-use prompts organized by workflow stage.

**How to access:** Click the three-dot menu in the AI Assistant panel → Select **Prompt library** → Browse and choose a prompt → Edit before using if needed

**How to use:** Each prompt is designed to be specific and purpose-driven. You can use them as-is or customize them for your context.
<!-- /SLIDE -->

<!-- SLIDE:m9_10 -->
## Prompt library organization

| Category | Purpose |
|----------|---------|
| **Getting started** | Orient yourself: what data is available? |
| **Data quality** | Check completeness, outliers, and validity |
| **Analysis** | Identify trends, compare regions, find priorities |
| **Indicator deep dives** | Focus on specific program areas |
| **Visualizations** | Create charts, heatmaps, comparisons |
| **Reports & communication** | Generate presentation decks and talking points |
| **Workflows** | Go from insight to slide, quick deck, or data story |
| **Methodology** | Understand how FASTR works |
| **Standardized reports** | Generate full disruption reports with guided prompts |

## Activity: Creating a disruption report with the AI Assistant

![hands-on h:40](resources/icons/hands_on.svg) **Step by step:**

1. Open the **Slide Decks** tab → Create a new slide deck (e.g., "Disruption Report for {country}")
2. Open the **AI Assistant** → Start a new conversation
3. Open the **Prompt Library** → Select **"Prompt 1: FASTR Disruptions Report"**
4. Review the prompt text that appears in the input field
5. **Run the prompt** → The AI will ask for: country name, analysis time period, and report subtitle
6. The AI will propose **indicator groupings** — review and confirm with your team
7. The AI builds the report slide by slide (5-10 minutes)

**Tip:** Let the AI complete the full slide generation before clicking on any slide — clicking will interrupt the process.
<!-- /SLIDE -->

## Alternative: Working from a PDF template

If you have a previous report you're satisfied with:

1. Upload the report PDF to your **Assets** (main page → Assets → Upload)
2. In the AI conversation, click the three-dot menu → **Include file** → Select the report
3. Ask the AI: *"Use this report as a template. Create a similar report covering [time period]."*

**Use this approach when:**
- You have a previous report you are satisfied with
- You want to replicate a similar format for a new period
- No custom prompt is available for that report type
<!-- /SLIDE -->

## Review checklist: Verifying the AI output

After the AI generates your report, review each section as a team:

**General**
- [ ] All slides were generated — none missing or incomplete
- [ ] Country name is correct and consistent across all slides
- [ ] Time period is correct on all charts
- [ ] No placeholder text remaining

**Disruptions report**
- [ ] Cover slide has correct country, subtitle, and date
- [ ] Indicator groupings match what you confirmed
- [ ] Each group has its own analysis slide
- [ ] Charts are loading and showing data (not blank)
- [ ] Interpretations match what the chart shows
- [ ] Slide titles are analytical, not just indicator names

**Final:** Read through all interpretations as a team — does anything sound wrong or exaggerated?
<!-- /SLIDE -->

## Editing and formatting your slides

Now that the AI has generated the report, review and polish each slide:

**1. Review each slide** — Check that all content is accurate and complete

**2. Resize text boxes** — Make sure interpretation text is fully visible and easy to read

**3. Resize and reposition visualizations** — Ensure charts are clear and well-balanced

**4. Adjust the layout** — Fine-tune spacing, alignment, and proportions

**Other edits you can make:**
- Edit the slide title via the Header field
- Edit interpretation text via the Content tab
- Add sub-header, date, or footer via the Header/Footer tab
- Ask the AI to revise the content of individual slides

*Tip: You can always ask the AI to rewrite a specific slide if the interpretation needs adjusting.*
