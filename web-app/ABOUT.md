# FASTR Deck Builder

A tool for creating customized workshop presentations for FASTR training.

---

## What is this app?

The FASTR Deck Builder helps you create PowerPoint presentations for FASTR workshops without starting from scratch. Instead of copying slides manually, you:

1. **Pick your content** from a library of pre-made slides
2. **Arrange your schedule** by dragging sessions around
3. **Export** a finished presentation ready to deliver

Think of it like building a playlist - you choose the songs (slides), arrange them in order, and hit play (export).

---

## Who is it for?

Anyone organizing or facilitating a FASTR workshop:
- Workshop coordinators
- Facilitators
- Technical advisors
- Country teams

No technical skills required - if you can use a website, you can use this app.

---

## What can you do with it?

### Create a Workshop

Start a new workshop by entering:
- Country and location
- Workshop dates
- Number of days
- Which FASTR modules to include

The app can automatically suggest a schedule based on your choices.

### Build Your Agenda

Your workshop appears as columns (one per day) with cards (sessions):

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   Day 1     │  │   Day 2     │  │   Day 3     │
├─────────────┤  ├─────────────┤  ├─────────────┤
│ Welcome     │  │ Day Recap   │  │ Day Recap   │
│ Introduction│  │ Data Quality│  │ Analysis    │
│ Tea Break   │  │ Tea Break   │  │ Tea Break   │
│ Module 1    │  │ Module 4    │  │ Module 6    │
│ Lunch       │  │ Lunch       │  │ Lunch       │
│ Module 2    │  │ Module 5    │  │ Wrap-up     │
│ ...         │  │ ...         │  │ Closing     │
└─────────────┘  └─────────────┘  └─────────────┘
```

You can:
- **Drag** sessions to reorder them
- **Click** a session to edit details (duration, speaker)
- **Add** new sessions from the content library
- **Remove** sessions you don't need

### Browse the Content Library

The library contains all FASTR content organized by module:

- **Module 0**: Introduction to FASTR
- **Module 1**: Identify Questions & Indicators
- **Module 2**: Data Extraction
- **Module 3**: FASTR Analytics Platform
- **Module 4**: Data Quality Assessment
- **Module 5**: Data Quality Adjustment
- **Module 6**: Data Analysis
- **Module 7**: Results Communication

Each module has multiple topics with pre-made slides. Click to preview, then add to your workshop.

### Use the AI Assistant

Need help? The AI assistant can:

- **Answer questions** about FASTR content
- **Suggest schedules** based on your needs
- **Add sessions** when you ask (e.g., "Add a tea break after Module 2")
- **Generate objectives** tailored to your workshop
- **Create custom content** for country-specific slides

Just type what you need in plain English.

### Preview Your Deck

See exactly how your slides will look before exporting. Navigate through slides to check content and flow.

### Export Your Presentation

When you're happy with your workshop, export it as:

- **PowerPoint (.pptx)** - Edit further in PowerPoint
- **PDF** - Share or print as-is
- **HTML** - Present directly in a web browser

## How does the content get there?

All slide content comes from the FASTR methodology documentation. When the methodology is updated, the slides can be refreshed to match. This means:

- Content stays consistent across all workshops
- Updates to methodology flow through to new decks
- You're always using the latest FASTR content

## Common Tasks

### "I need to create a 3-day workshop for Zambia"

1. Click **New Workshop**
2. Enter: Zambia, 3 days, your dates
3. Select the modules you want to cover
4. Click **Generate Schedule** - AI creates a draft
5. Adjust as needed
6. Export to PowerPoint

### "I want to add a group activity"

1. Open the Content Library
2. Find the activity slide or create a custom session
3. Drag it to the day you want
4. Adjust the duration

### "I need to shorten Day 2"

1. Click on sessions to see their duration
2. Remove or shorten sessions
3. Times automatically recalculate

### "I want to see what a module covers"

1. Open the Content Library
2. Click on a module to expand it
3. Click on topics to preview the slides

## Tips for Best Results

1. **Start with AI** - Let the AI generate a first draft, then refine it
2. **Preview often** - Check how slides look before exporting
3. **Use breaks wisely** - The app includes standard tea (15 min) and lunch (60 min) breaks
4. **Save frequently** - Your work saves automatically, but check the save indicator
5. **Lock finished workshops** - Prevents accidental changes

## Frequently Asked Questions

**Q: Can I edit the slides after exporting?**
A: Yes! The PowerPoint export is fully editable. You can add your own slides, change text, etc.

**Q: What if I need country-specific content?**
A: You can create custom sessions with your own content, or ask the AI to generate country-specific slides.

**Q: Can multiple people work on the same workshop?**
A: Yes, but not at the exact same time. The last person to save will overwrite earlier changes.

**Q: How do I delete a workshop I don't need?**
A: Open the workshop selector (top left), hover over the workshop, and click the trash icon. You'll need to unlock it first if it's locked.

**Q: What browsers work best?**
A: Chrome, Firefox, Safari, and Edge all work. Use a recent version for best results.

**Q: Can I use this offline?**
A: No, you need an internet connection to use the app.
